근무일 달력 - 설치 안내
======================

기능
- 출근/퇴근 버튼을 한 번 눌러 오늘 날짜와 현재 한국 시간(Asia/Seoul)을 각각 저장합니다. 이미 저장된 시간은 덮어쓰기 전에 확인합니다.
- 월별 달력에 근무일이 표시됩니다.
- 날짜를 눌러 출근/퇴근 시간을 직접 수정하거나, 놓친 근무일을 추가할 수 있습니다.
- 이번 달 기록을 최신순/오래된순으로 전환할 수 있고, 선택한 순서대로 근무 날짜 및 출퇴근 시간 목록을 복사할 수 있습니다. 날짜 표시 형식도 세 가지 중 선택할 수 있습니다.
- 지원하는 Android 설치형 브라우저에서는 앱 아이콘을 길게 눌러 출근/퇴근 바로가기를 사용할 수 있습니다.
- 기록을 JSON 파일로 백업/복원할 수 있습니다.
- 설치 후 오프라인에서도 앱 화면을 열 수 있습니다.

중요: 기록 보관과 PC 동기화
- 기록은 서버가 아니라 해당 기기 브라우저의 저장 공간에 보관됩니다.
- 휴대폰과 PC가 같은 웹 주소를 열어도 기록이 자동으로 동기화되지는 않습니다.
- PC에서도 같은 기록을 쓰려면 휴대폰에서 '기록 백업하기'로 JSON 파일을 저장하고, PC에서 '백업 파일 가져오기'를 선택하세요.
- 브라우저 데이터/사이트 데이터를 삭제하면 기록이 사라질 수 있으니 주기적으로 백업하세요.

홈 화면에 추가하기 (HTTPS 주소로 배포한 뒤)
-----------------------------------------
GitHub Pages 예시:
1. GitHub에서 새 저장소를 만들거나 기존 저장소에 이 폴더 안의 파일을 업로드합니다.
   index.html, manifest.webmanifest, sw.js, icons 폴더가 같은 최상위 폴더에 있어야 합니다.
2. 저장소 Settings > Pages에서 배포할 브랜치와 폴더를 선택해 사이트를 켭니다.
3. Pages가 알려 주는 https://... 주소를 휴대폰에서 엽니다.
4. Android/Chrome: 메뉴(⋮) > '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.
   iPhone/Safari: 공유 버튼 > '홈 화면에 추가'를 선택합니다.
5. 홈 화면의 '근무일' 아이콘을 누르면 앱처럼 열립니다.
6. Android/Chrome에서 앱 바로가기가 표시되면 홈 화면 아이콘을 길게 눌러 '출근 기록' 또는 '퇴근 기록'을 실행할 수 있습니다. 지원 여부는 기기/브라우저에 따라 다릅니다.
   기본 아이콘을 한 번 누르는 것만으로는 기록하지 않고 앱을 엽니다. iPhone은 보통 홈 화면 웹 앱 안의 버튼을 눌러 기록해야 합니다.

PC 사용
- 같은 HTTPS 주소로 열면 넓은 화면에 맞춰 달력과 편집 화면이 표시됩니다.
- 기기간 기록을 옮길 때는 JSON 백업 파일을 사용하세요.

개인정보
- 이 기본 버전은 외부 서버로 근무 기록을 전송하지 않습니다. 브라우저 안에만 저장합니다.
